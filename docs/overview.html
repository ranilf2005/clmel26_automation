Overview

An infrastructure-as-code approach to deploying and testing network configuration.

About this solution

In this lab, you manage abstracted network configurations in YAML format using a version control system hosted in GitLab. You will:

  • Manage a network configuration in the Git version control system.
  • Leverage network test scripts using the pyATS framework and Cisco Modeling Labs APIs.
  • Build a CI/CD pipeline that automatically deploys network changes using Ansible into a virtual network provided by CML.
  • Run the pyATS test scripts to validate the changes.
  • Deploy your configuration into production.

This lab highlights the following:

⚙

Infra as Code

Deploy and test configuration in a network from a declarative source of truth.

✓

Operational testing

Validate intended configuration results before deploying into production.

▤

CML testbed

Use CML to provide a safe, disposable testbed for network changes.

You work with a CML lab topology in which there are two labs with an identical topology: one for production and one for testing. Use the testing lab to stage your configuration changes and run test cases. When those test cases are successful, merge that configuration into your main configuration and deploy it to production.

Intended audience

This demonstration is designed for users with CCNP-level networking knowledge and basic familiarity with network simulations. A working knowledge of the following is expected:

Cisco Modeling Labs (CML) Ansible pyATS GitLab Visual Studio Code vim / nano
Important

If you do not have the knowledge specified above, you may not be able to complete this lab. Review the reference material for each technology before you begin.
