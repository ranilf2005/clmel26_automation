NetDevOps — Network Automation

Build, Test, Stage, and Apply network configuration as code using Cisco Modeling Labs (CML), pyATS, Ansible, and a GitLab CI/CD pipeline.

About this lab

In this lab you manage abstracted network configuration in YAML under version control in GitLab. A CI/CD pipeline automatically validates every change against a virtual network running in CML, and only deploys to the devices when all tests pass — an infrastructure-as-code approach to network operations.

Infrastructure as Code

Every network change is committed to Git, tested with pyATS in a CML testbed, and applied automatically only after the health checks succeed. If a test fails, the pipeline stops and the network is never touched.

What you will do

1

Version-control the network

Store router configuration intent as YAML in a Git repository hosted in GitLab-CE.

2

Automate tests with pyATS

Run reachability and static-route consistency checks against live CML devices.

3

Gate deployment on tests

A GitLab pipeline deploys Loopback300 only when every test passes.

4

Observe pass / fail

Review pipeline results in GitLab CI/CD, then verify the change on the routers.
